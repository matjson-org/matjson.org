# Reference documentation v10

This release improves information architecture, maturity labeling, and local preview behavior.

## Navigation

The primary navigation now uses two focused dropdowns: Profiles and Docs. Home and About remain direct links, while Resources remains a project hub. Profile maturity is visible in the Profiles menu.

## Profile status

MatSpecJSON and MatReqJSON are marked Working draft; MatJSON Core is Draft; MatRecordJSON and MatCheckJSON are Concept / WIP placeholders.

## Local preview

Reference pages embed their schema JSON so the interactive viewer works when opened directly from a local file. Relative directory links now point explicitly to index.html, preventing browser directory listings.

## Compatibility

The published MatSpecJSON v0.2.10 and MatReqJSON v0.2 schemas are unchanged.
