RFC process

Major semantic changes should be documented through short, versioned MatJSON RFCs or architecture decision records.

MJ-RFC-0001 Core terminology and profiles
MJ-RFC-0002 Units and quantities
MJ-RFC-0003 Rule applicability expressions
MJ-RFC-0004 Source-document invocation
MJ-RFC-0005 Compliance evidence model

Review levels

Technical review should be traceable to a reviewer, source edition, scope, and date. Automated extraction and schema validation cannot substitute for independent engineering review.
