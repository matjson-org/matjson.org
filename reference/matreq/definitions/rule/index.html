Fields

FieldTypeStatusMeaning
idstring — pattern ^[A-Za-z0-9._:-]+$RequiredStable rule identifier used for invocation, dependencies, checking, and result traceability.
titlestringOptionalShort human-readable statement of the rule.
categoryenum — "material_selection", "product_form", "chemistry", "mechanical", "impact", "hardness", …RequiredControlled material-requirement category used for filtering and downstream processing.
normativityNormativityRequiredThe source document's normative strength and modal wording, kept separate from project activation.
targetsTargetsRequiredMaterials, grades, product forms, equipment components, weld regions, sides, services, and fabrication states to which a rule can apply.
activationActivationRequiredHow a rule becomes active for a purchase, including always-active, conditionally active, purchaser-invoked, or scoped invocation.
requirementRequirementRequiredThe typed behavior imposed by the rule, such as a limit, test, examination, heat treatment, document field, prohibition, or decision procedure.
effectEffectOptionalHow a MatReq rule supplements, restricts, replaces, selects, prohibits, or otherwise interacts with a base MatSpec requirement.
verificationVerificationRequiredEvidence types, checking method, and result behavior used to demonstrate compliance.
dependenciesDependenciesOptionalOther rules, decisions, or external documents needed before this rule can be evaluated.
referencesarrayOptionalExternal documents invoked or used by this rule, together with the precise reference role.
sourceSource refRequiredPrimary source locator for the rule. Use sources when multiple noncontiguous locations jointly establish it.
notesarrayOptionalAdditional interpretation or extraction notes that do not replace the structured rule.
group_idstringOptionalIdentifier linking related atomic rules that originate from one larger source requirement or decision sequence.
structured_levelenum — "fully_structured", "partially_structured", "text_preserved", "lookup_required"OptionalDegree to which the source requirement has been converted into executable structure rather than preserved text or a lookup.
sourcesarray — at least 1 item(s)OptionalOne or more source locations jointly supporting the rule.
extensionsobjectOptionalNamespaced workflow or domain data associated with this rule.
