Fields

FieldTypeStatusMeaning
accepted_sourcesarrayRequiredDocuments from which an invocation may be established. The material requisition remains the project-specific source of truth; these fields merely identify the documents that may contain the same requisition requirements.
document_referenceobjectRequiredWording patterns and behavior for invoking the entire governing document from a requisition.
scoped_referenceobjectRequiredWording patterns and behavior for invoking only a named part, section, annex, appendix, table, figure, or clause.
direct_rule_referenceobjectRequiredBehavior when the requisition states a requirement directly, whether or not it cites the source document.
contractual_reference_strengthobjectRequiredA material requisition may elevate an otherwise informative/example source scope into a binding contractual requirement when it explicitly requires compliance, e.g. 'Material must meet API TR 938-C Appendix A'. Merely saying 'refer to' or 'see' does not by itself create the same obligation.
cross_reference_policyobjectRequiredRules for deciding whether an internal reference imports another document fully, only a method or criterion, or merely guidance.
