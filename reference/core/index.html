Overview

MatJSON Core is intended to prevent profile drift by defining common semantic building blocks once and reusing them across MatSpec, MatReq, MatRecord, and MatCheck. The current file is an architectural placeholder.

Shared semantics

Profiles should reuse one definition of quantities, source locations, expressions, and extensions.

Controlled vocabularies

Stable identifiers allow industries to add terms without fragmenting the core format.

TBC

The placeholder communicates the intended architecture; it is not ready for production implementation.
