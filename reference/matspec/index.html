JSON Schema

This page shows the published JSON Schema as one formatted document. Use the chevrons to fold objects and arrays, follow highlighted objects and $ref values within the schema, and use the book icons to open definition guides. You can also open the raw schema file.

Version naming: the published v0.2 schema retains matspec for compatibility. The proposed v0.3 direction is "matjson": {"profile": "matspec", "version": "0.3"}, so profile identity and version remain explicit.
