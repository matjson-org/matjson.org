MatJSON Core — shared semantics for materials data

The shared semantic layer for values, units, provenance, expressions, selectors, identifiers, vocabularies, citations, and extensions.

Draft · v0.1Internal/common schema

Overview

MatJSON Core prevents profile drift by defining primitives once and reusing them across MatSpec, MatReq, MatRecord, and MatCheck.

Open the linked schema

Read the actual JSON Schema with stable object anchors, linked $ref values, and human-readable definition guides.

Open linked schema

Planned primitives

  • Typed quantities, units, ranges, and rounding
  • Source citations and multi-range provenance
  • Boolean and numeric expression trees
  • Material, product-form, component, service, and evidence vocabularies
  • Namespaced extensions

Status

TBC: The included Core schema is an architectural placeholder. The current MatSpec and MatReq schemas still contain profile-local definitions that should later migrate into Core.
