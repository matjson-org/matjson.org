MatCheckJSON

A proposed machine-readable format for auditable material-compliance outcomes.

Concept accepted · TBC.matcheck.json

Overview

MatCheckJSON will preserve the exact requirement evaluated, its origin, applicability, evidence, comparison, result, explanation, and review state.

Planned outcomes

  • Pass and fail
  • Not applicable
  • Needs project input
  • Missing evidence
  • Requisition gap
  • Manual review required

Status
