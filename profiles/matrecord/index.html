MatRecordJSON — JSON format for MTR and CMTR data

A proposed normalized representation of MTRs, CMTRs, test reports, and related evidence.

Concept / WIP · v0.1 placeholder.matrecord.json

Overview

MatRecordJSON will provide one common evidence model across widely varying mill certificates, laboratory reports, heat-treatment records, NDE reports, and inspection documents.

Open the linked schema

Read the actual JSON Schema with stable object anchors, linked $ref values, and human-readable definition guides.

Planned content

  • Document identity, issuer, dates, and source file
  • Material specification, grade, heat, lot, product form, and condition
  • Reported chemistry, mechanical properties, and heat treatment
  • Tests, NDE, PMI, certification, and traceability
  • Extraction provenance and confidence
